# Harness Session Plus

为 Windows 版 DeepSeek Harness 提供会话搜索、上下文恢复、关注提醒、会话回收站和皮肤中心的独立桌面工具。通过本机 Chrome DevTools Protocol（CDP）连接，使用已验证的原生只读查询及归档与恢复机制。

当前源码版本：**0.9.0**（本地开发，尚未发布）。已发布桌面版仍为 0.8.0。采用 Rust + Tauri 2，前端使用 HTML/CSS/JavaScript，没有 Node 后端或 Electron 宿主，不修改 Harness 安装包。

> “移入回收站”是可恢复的原生归档。**永久删除尚未实现，按钮保持禁用**；“检查删除能力”只读取状态，不删除文件或会话。

## 快速开始

### 1. 构建桌面程序

需要 Windows Rust MSVC 工具链、Visual Studio C++ 构建工具（含 Windows SDK）和 WebView2 Runtime。首次构建需要下载 Cargo 依赖。

先进入**项目根目录**，确认存在 `desktop/src-tauri/Cargo.toml`：

```powershell
cd C:\path\to\harness-session-plus
cargo build --manifest-path desktop/src-tauri/Cargo.toml --release --locked
& .\desktop\src-tauri\target\release\hsp-desktop.exe
```

静态前端嵌入 EXE，不需要 npm。当前没有生成 MSI/NSIS 安装包，也没有代码签名。更新时从托盘退出旧管理工具，再打开新版。

### 2. 开启 Harness 调试连接

在“设置”配置 Harness 可执行文件路径，然后在“连接与增强”点击“启动 Harness”。也可以手动启动：

```powershell
& "$env:LOCALAPPDATA\Programs\DeepSeek Harness\DeepSeek Harness.exe" --remote-debugging-port=9223 --remote-debugging-address=127.0.0.1
```

已运行且开启端口的 Harness 可以直接连接。如果普通启动时未开启端口，需要保存工作、正常退出，再带参数启动；重复启动不保证参数对已有实例生效。工具不会强制结束 Harness。

检查本机监听：

```powershell
Get-NetTCPConnection -LocalPort 9223 -State Listen
```

期望地址为 `127.0.0.1`。默认端口 9223，可在设置修改；多个页面需要明确选择目标。

调试服务可访问时，下面的只读命令会返回浏览器信息和页面列表：

```powershell
Invoke-RestMethod http://127.0.0.1:9223/json/version
Invoke-RestMethod http://127.0.0.1:9223/json/list
```

工具选择的是 `type = page`、`url = dsh-app://app/` 的页面。端口可访问只说明调试服务在运行；安装增强还需要通过版本、profile 和会话能力核验。

### 3. 安装和使用回收站

1. 点击“检查连接”，确认识别到 Harness 页面。
2. 在“会话回收站”点击“安装回收站增强”。
3. 重新打开 Harness 会话的“…”菜单，点击“移入回收站”并确认。
4. 通过侧栏入口或管理窗口进入回收站，搜索并单项或批量恢复。

关闭窗口会隐藏到托盘。退出管理工具不会移除已应用的皮肤：独立主题守护会按保存配置恢复 Harness 页面样式。电脑重启、用户注销或手动结束守护后，需重新打开工具启动守护；本版不设置开机自启。用户主动安装回收站增强后，工具会保存本机增强偏好；管理工具重启、Harness 页面刷新或 Harness 重启后，下一次连接检查会重新核验版本、profile 和唯一页面，菜单缺失时自动恢复增强。自动恢复只安装页面增强，不会归档、恢复、删除会话，也不会重放断线前请求。断线后停止接收菜单动作，自动恢复失败时显示手动恢复提示。

## 操作保护和数据保存

### 皮肤中心使用

打开“皮肤中心”，选择一张卡片，再点击“应用到 Harness”。卡片展示配色及壁纸，选择卡片不会修改 Harness。可用“检查皮肤状态”核对当前页面，点击“恢复 Harness 默认”移除本工具的样式覆盖。

通过现有 CDP 连接覆盖已识别的 `--dsw-*` 主题变量，不调用未验证的插件接口、不修改 Harness 安装包或原生主题偏好，不读写会话。缺少主题变量、目标页面不明确或存在未知同名样式时拒绝应用。选择主题后可调节背景清晰度（0–100%，默认 70%），点击“应用到 Harness”后配色、壁纸和清晰度会一起保存到本机。独立后台主题守护每三秒检查页面，并在样式丢失或版本不符时恢复；只连接到唯一的 Harness 页面，多个候选页面时不会自动选择。退出管理工具不清除主题；点击“恢复 Harness 默认”会先停止自动恢复，再移除页面覆盖。

内置四套配色，全量收录当前 [CodexPlusPlus 主题市场](https://github.com/BigPizzaV3/CodexPlusPlus-Themes/blob/main/index.json)的 **39 款主题**及 Codex++ Windows 内置的 **桥本有菜**，共 44 款本地主题。支持名称、作者和标签搜索、来源分类、12 张卡片分页。来源与许可见[主题素材说明](desktop/ui/themes/README.md)，实现分析见[Codex++ 主题分析](docs/codex-theme-analysis.md)。

“DreamSkin 社区”需要主动点击“加载 / 刷新社区”才联网，按 48 条分页浏览接口条目（本次返回 741 条，数量动态变化）。点击“安装到我的主题”，确认作者与许可后下载；核对版本、包和素材摘要，再转换配色与图片。安装不自动应用，已安装主题可离线使用，不占用手动导入的 20 个名额。旧格式、图片超过 5 MiB、许可或图片缺失及校验失败会显示拒绝原因，不能保证所有社区条目都兼容。

其他 Codex++ 主题可以通过“导入主题”加入：

1. 如果下载的是 ZIP，先解压，选择其中的 `theme.json`（`schemaVersion: 1`，最大 64 KiB）。
2. 可选对应的 PNG、JPEG 或 WebP 背景图片（最大 5 MiB），填写作者与许可信息。
3. 点击“导入到我的主题”。导入保存到本机，不会自动应用；选择新卡片，再点击“应用到 Harness”。

最多保存 20 个手动导入主题，重启管理工具后仍可选择。转换器读取背景、面板、文字、强调色和边框颜色，不运行包内 CSS、脚本或插件，不自动同步离线市场或移植 Codex 专属布局。手动导入的 ZIP 需解压；社区 ZIP 由专用流程在内存校验。不是所有 Codex++ 主题格式都兼容。填写许可信息仅用于记录来源，不代表工具确认了素材授权。

皮肤仅作用于 Harness 页面，需保持 Harness 的本机调试端口可访问。断线后守护会等待；页面重新上线后会重新查找唯一目标并恢复，通常最多有数秒延迟。电脑重启或用户注销后需打开工具一次启动守护，本版不设置开机自启。主题保持详见[主题保持说明](docs/persistent-themes.md)。它与管理窗口的明暗主题独立，不覆盖代码语法及成功、错误等语义配色。已验证 40 款内置/市场转换主题的壁纸、核心配色及默认恢复；完整退出并重启 Harness 的流程尚未实测，部分组件、原生窗口或第三方插件也可能保留原色。

### 会话操作

- 执行前核对安装版本、监听进程、backend profile、真实会话 ID、工作区及原生状态。
- 运行中或运行状态未知时拒绝操作；归档不携带 `stopActivity`，原生接口还会检查活动 provider。
- 先事务保存操作意图，再调用原生接口，最后独立读取归档集合、会话及工作区核对结果。
- 超时或断线保留“结果未确认”，重连后只读核对，不自动重试数据操作。
- 恢复仅允许当前 profile 下由工具收录、归档状态已确认的会话。
- 退出尝试卸载增强；无法确认时显示提示，保留 Harness 运行。

工具数据保存在 Tauri `app_config_dir`：

| 文件 | 用途 |
| --- | --- |
| `settings.json` | 连接、程序路径、管理窗口主题配置 |
| `active-theme.json` | 当前应用的完整 Harness 主题、清晰度及恢复版本 |
| `imported-themes.json` | 本地导入主题的颜色、图片及来源信息 |
| `community-themes.json`、`community-themes/` | 已安装社区主题清单及独立主题文件（含图片与上游 manifest） |
| `session-checkpoints.json` | 用户主动保存的会话 profile、真实 ID、标题、工作区、路径和继续提示词 |
| `session-favorites.json` | 用户主动收藏的会话 profile、真实 ID、标题和工作区 |
| `session-tags.json` | 用户主动设置的会话 profile、真实 ID 和标签 |
| `session-notes.json` | 用户主动保存的本机备注，按 profile 和真实会话 ID 隔离 |
| `prompt-templates.json` | 用户编写的个人提示词模板 |
| `recycle.sqlite3` | 回收站元数据及操作日志，可能伴有 WAL/SHM 文件 |
| `capability-report.json` | 用户主动导出的结构报告 |

回收站元数据包含 ID、标题、工作区名称，不保存聊天正文。结构报告不采集正文、认证数据或属性值。构建产物和本机提取的源码证据位于被 Git 忽略的 `target/`。

备份工具记录时，先从托盘正常退出，再复制应用配置目录。`recycle.sqlite3` 是记录与核对依据，不能代替 Harness 自身会话数据的备份。不要通过删除这个数据库来“清空会话”：这会丢失工具记录，并不会永久删除 Harness 中的会话。

## 会话中心：搜索 → 恢复上下文 → 关注 → 返回

1. 在桌面工具任意页面按 Ctrl+K 打开快速切换器；输入标题、工作区、路径、会话 ID 或标签过滤已加载会话，按方向键和 Enter 导航。候选最多显示 30 项，首次使用会自动打开会话中心并加载列表。也可打开“会话中心”，点击“刷新会话”，按标题、工作区、路径或 ID 即时筛选；输入对话关键词后点击“搜索正文”。可进一步按工作区、运行状态、归档状态或“已收藏”筛选；打开会话后点击“收藏会话”即可保存常用入口。
2. 选择会话，查看真实消息摘录和事件序号。填写“下一步想做什么”，生成可编辑的继续任务提示词；点击“复制提示词”或“导出 Markdown”。点击“回到 Harness 会话”后可手动粘贴发送，本工具不会自动发送消息。
3. 点击“关注此会话”，每 10 秒检查变化。首次读取仅建立基线，避免把旧状态当成新通知。支持取消单项关注和停止全部关注。
4. 可勾选 Windows 通知，并先用“测试桌面通知”核对系统设置。通知不显示会话标题或正文；点击后返回工具并按真实会话 ID 打开 Harness 会话。工具完全退出后停止关注，关闭到托盘时继续。

当前安装的 Harness 将正文索引设为 `openAt: never`。工具不会修改此配置，而是自动回退到只读搜索最近消息：最多扫描 50 个普通非空会话、每个最近 20 条消息，最多三个并发读取，并在界面显示扫描数、读取失败数和范围限制。**这是有界搜索，不能保证覆盖全部历史正文**。原生索引可用时使用原生搜索，最多返回 20 个命中；没有命中不代表全历史没有相关内容。

“会话摘要”是最近一页的原文摘录，最多 20 条用户/助手文本消息、每条最多 6000 个 UTF-16 单元。不会生成未经验证的语义总结，也不读取图片、附件、工具输出或推理内容到提示词中。历史对话以引用标记；生成内容不代表文件现状、测试结论或任务已经完成。

“个人提示词库”位于会话详情的最近摘录下方，可新建、编辑、删除、按名称/分类/内容搜索模板。模板保存在工具数据目录的 `prompt-templates.json`，最多 100 条，每条名称最多 80 字、分类最多 40 字、正文最多 2000 字。选择“填入下一步”会把模板追加到当前会话的下一步请求；超过输入长度时保留原内容并提示。模板和会话请求都不会自动发送，备份默认包含模板，备份文件未加密。

“本机备注”按 profile 和真实会话 ID 保存在 `session-notes.json`，每条最多 4000 字符、最多 500 条。备注会作为独立背景段落加入继续任务提示词，并明确提示可能过时；切换 profile 不会混用备注。清空后保存即可移除。备注可能含敏感项目背景，默认随工具备份迁移，备份未加密。

点击“保存检查点”会把当前会话的 profile、真实会话 ID、标题、工作区、路径和可编辑继续任务提示词保存到本机 `session-checkpoints.json`，最多 100 个。点击“恢复检查点”时会重新识别 Harness 实例，核对 profile、会话 ID、标题、工作区和未归档状态，再打开对应会话并载入提示词；不自动发送、不恢复聊天正文、不修改项目文件，也不回滚 Git 工作树。切换 profile 后检查点只可删除，不能直接恢复。

“收藏会话”会在本机 `session-favorites.json` 保存当前 profile、真实会话 ID、标题和工作区，最多 200 条；“已收藏”筛选只显示当前 profile 的收藏。它不修改 Harness 数据、不保存聊天正文，并随工具数据备份迁移。

自定义标签保存于本机 `session-tags.json`，按 profile 和真实会话 ID 隔离。每会话最多 8 个、每个最多 32 字符；可用逗号输入多个标签，搜索框也会匹配标签。清空输入并保存即可移除该会话的全部标签，不影响会话本身。备份默认包含标签。

列表中的“批量整理”与“选择会话比较”互斥。批量整理最多选择 100 个当前列表会话，可批量收藏、取消收藏或追加标签；标签只会添加缺少项，不替换原标签。操作逐条执行，达到单会话标签数量上限时保留该项原标签，并显示部分成功/失败数量。选择 10 个或更少时可将经过序号核实的最近文本摘录汇总为一个 Markdown；每条消息最多 3000 个字符，附件、工具输出及推理内容不包含在内。

同一页面的“Git 工作区（只读）”按所选会话目录运行 `git status` 与最近提交查询，分别展示分支、暂存修改、工作区改动和未跟踪文件。点击“读取差异”可查看已跟踪文件的暂存与未暂存 diff；每个区域最多读取 96 KiB，10 秒超时，超限时停止读取并标明截断。未跟踪文件仅显示路径，不读取内容。没有 Git 或目录不属于仓库时显示明确错误。检查不创建提交、不暂存文件、不切换分支、不改索引；差异查询禁用外部 diff、textconv、颜色与分页，并忽略可选锁、禁用 fsmonitor 检查器。

同一页面的“项目规则（只读）”默认检查工作区根目录的 `AGENTS.md`、`CLAUDE.md`、`.clinerules`、`CONTRIBUTING.md`，以及 `.cursor/rules`、`.windsurf/rules`、`.clinerules` 下的 Markdown 规则文件。最多读取 32 个文件、单文件 32 KiB、总计 256 KiB；符号链接、其他路径和未列出的文件不会读取。内容只作为普通文本展示，不执行规则、不自动修改提示词，也不写回项目。

“模型、用量、权限与协作模式”从已验证的 `session/projections` 读取 Harness 的 `modelSelection`、`tokenUsage`、`contextPressure`、`permissions.currentValue` 和 `plan` 投影：Token 汇总仅展示持久历史中的提供方报告值；压力项是最近观测值，不等于 Token 账单，也不保证与模型选择来自同一原子时刻。权限预设及计划模式只读显示，不提供切换。投影迁移中、缺字段或不支持时不读取缓存数字来冒充实时数据，逐项显示不可用。不会通过最近消息估算累计 Token，也不会发起模型请求。

计划模式快捷命令按当前投影状态复制 Harness 支持的 `/plan` 或 `/plan off`。该操作只写剪贴板，不会自动发送、切换模式或提交消息；计划状态待生效或不可用时禁用。

会话详情还会按当前会话读取 Harness 已验证的 `skills/list` 元数据，展示技能名称及是否允许模型调用。该目录读取不激活冷会话、不读取技能文件正文、不执行技能，也没有安装、编辑或删除按钮；接口不可用时只显示原因。

“后台任务”通过已验证的 `job/list` 流取得所选会话的完整当前名册快照，然后立即关闭读取流；可手动刷新。显示任务类型、命令、状态、进度/终态摘要和 Harness 报告的保留输出字节数。不会订阅输出、调用停止命令、启动任务或改动 job 状态；页面提示这是快照而非持续实时更新。

运行状态来自原生列表；等待交互状态只读取已确认结构的侧栏 React 状态，无法观测时标记未知。仅在观测到新状态时提醒；停止运行只提示查看结果。若只读读回的新 `turn/end` 事件明确为 `error` 且事件序号晚于上次基线，才提示错误。10 秒轮询可能遗漏两个检查之间短暂出现的状态。导航依赖 Harness 侧栏已渲染的真实回调，工作区未展开时需展开后重试；不会用标题或 DOM 序号选择会话，也不会为打开会话自动取消归档。

断线、配置变更或 profile/进程代次改变后关注停止，需要重新开启。当前不会持久保存搜索正文或关注清单；只有主动复制、导出的内容会离开内存。导出保存至工具配置目录的 `exports/`，内容可能包含聊天及项目路径，请在分享前检查。首次启用/测试 Windows 通知会在当前用户注册本工具的通知身份（`HKCU\Software\Classes\AppUserModelId\com.harness-session-plus.manager`），并创建开始菜单的 `Harness Session Plus Notifications.lnk`；这是普通启动快捷方式，不是开机自启。系统禁用或拒绝通知时保留工具内提醒。通知点击的会话路由需要工具进程仍在运行，完全退出后不保证旧通知可恢复原会话。

适配与验收详情：[会话中心验证](docs/session-center-validation.md)。

## 安全备份与迁移

在“设置 → 安全备份与迁移”点击“创建备份”。ZIP 与 SHA256 文件保存在工具数据目录的 `backups/`，可直接点击“打开备份目录”。默认包含连接配置、手动导入及已安装的社区主题、当前皮肤副本、会话检查点、收藏、标签、本机备注和个人提示词模板；默认排除本机连接路径和回收站管理记录，后两项可主动勾选。检查点可能含会话摘录和工作区路径；备注和提示词模板由用户编写，可能包含敏感内容。备份未加密，主题包的作者及许可信息也会保留。

恢复时先选择 ZIP、点击“校验并预览”，核对每个新增或覆盖文件，再勾选确认并安排下次启动恢复。需要先卸载页面增强、恢复 Harness 默认皮肤；从托盘完全退出管理工具，再打开新版。可在重启前取消任务。恢复前会自动备份现有工具数据，替换失败或中断后按事务日志回滚；回滚未完成时停止启动。恢复时关闭自动回收站增强偏好，皮肤只加入可选主题，需手动应用；连接页面 ID 会清除。

**这是本工具的数据备份，不包含 Harness 会话正文、附件或项目文件，不能用于找回已丢失的 Harness 会话。** 回收站记录包含标题、工作区及 profile 标识，恢复后仍按原 profile 隔离，不会映射到其他实例。不在清单中的文件保留，不恢复关注清单或后台任务。当前只接受相同工具版本的备份，ZIP 最大 64 MiB、解压总量最大 192 MiB。SHA256 检查完整性，不证明来源可信。

“导出脱敏诊断”无需连接 Harness，只生成工具版本、平台与状态布尔摘要；适合反馈配置文件是否存在、是否登记后台任务等问题，不代表实时连接测试。完整范围及恢复排查见[备份与迁移说明](docs/backup-migration.md)。

## CLI

CLI 用于诊断及测试注入；真实回收站操作由桌面工具完成：

```powershell
cargo run --locked -p hsp-cli -- diagnose --port 9223
cargo run --locked -p hsp-cli -- inject-test --port 9223
cargo run --locked -p hsp-cli -- remove-injection --port 9223
cargo run --locked -p hsp-cli -- probe-capabilities --port 9223
```

`inject-test` 只加入连接测试按钮，不归档或删除。多个匹配页面需要 `--target-id <ID>`；页面 ID 不是持久实例身份。`--retries 0..3` 只重试连接初始化，默认 2 次，不重放注入或业务操作。JSON 输出到 stdout，失败输出到 stderr，退出码非零。

## 常见问题

**manifest path 不存在？** 先进入项目根目录，或使用 manifest 的实际绝对路径。根目录 `cargo build` 只构建 core/CLI，不构建独立桌面包。

**无法连接？** 检查调试参数、端口和监听地址。已普通启动的实例通常需要正常退出后重启。

**必须从本工具启动 Harness 吗？** 不需要。通过快捷方式、终端或其他启动器开启本机调试端口的实例也可连接。已经运行但没有调试端口的实例需要正常退出后带参数重启。

**只有原菜单？** 在新版工具安装“回收站增强”，关闭并重新打开会话菜单，避免同时运行旧版。身份无法唯一核实时按钮会禁用并显示原因。

**只看到“回收站 · 连接测试”？** 这是测试增强，不会修改会话。进入“会话回收站”安装回收站增强，然后重新打开会话菜单。

**显示不兼容或无法核实 profile？** 当前只适配上文列出的安装包摘要和 profile 结构。能力探测报告可以帮助定位差异；不能靠修改版本标签或跳过检查保证兼容。

**回收站为空？** 仅显示当前 profile 下由工具移入的会话。自行归档的记录不会导入；恢复成功的记录不再显示。

**恢复后显示“结果未确认”？** 保持原 Harness 实例和 profile，重新检查连接并刷新回收站，让工具只读核对实际状态。不要连续重复操作。

**点击关闭后工具还在运行？** 窗口关闭会隐藏到托盘。要更新或彻底退出，请使用托盘退出或设置页“退出工具”。

**为什么不能永久删除？** 当前适配版本没有已验证的原生会话删除接口。清搜索索引不等于删会话；离线日志清理需要另行核实引用、锁、缓存、附件和备份恢复。当前只有只读预检，见[删除审计](docs/permanent-delete-audit.md)。

## 开发和验证

```powershell
cargo fmt --all -- --check
cargo clippy --locked --workspace --all-targets -- -D warnings
cargo test --locked --workspace
cargo fmt --manifest-path desktop/src-tauri/Cargo.toml -- --check
cargo clippy --manifest-path desktop/src-tauri/Cargo.toml --locked --all-targets -- -D warnings
node --test fixtures/*.test.cjs
```

Node 仅用于开发脚本和 JS 模拟测试，不是产品运行依赖。当前工作区通过 workspace/core 与桌面合计 33 项 Rust 测试、37 项 JS 测试，core/desktop Clippy 零警告。主题守护的真实 Harness 验收细节和限制见[主题保持说明](docs/persistent-themes.md)。

2026-10-19，0.8.0 本地 release 构建成功，workspace 与桌面合计 28 项 Rust 测试、35 项 JS 测试通过，桌面 Clippy 零警告。本次备份恢复测试全部使用临时合成数据；尚未执行真实用户配置恢复或完整桌面交互验收，详见[备份与迁移说明](docs/backup-migration.md)。

2026-10-16 新增 0.7.0 连接恢复助手：保存用户主动启用的回收站增强偏好，管理工具或 Harness 重启后连接检查会重新核验并恢复缺失菜单；自动恢复不重放会话数据操作。会话中心的 Rust、JS 与真实本机验证记录继续见[会话中心验证](docs/session-center-validation.md)。

真实 Harness 验收使用两个新建同名专用会话：仅按指定 ID 归档其中一个，再恢复并核对工作区，另一个未被归档。没有执行真实永久删除。模拟测试不能替代完整窗口、托盘及升级兼容验收，见[回收站验证](docs/recycle-validation.md)。

`crates/core/examples/recycle_acceptance.rs` 会创建并变更新建测试会话，**不是只读测试**，仅应在专用验收环境主动运行。

## 项目结构

```text
crates/core/          Rust CDP、发现、适配器、SQLite、回收站业务
crates/cli/           Rust CLI 诊断与测试注入
desktop/src-tauri/    Tauri 宿主、commands 与托盘
desktop/ui/           HTML/CSS/JavaScript 管理窗口
injected/            Harness 菜单增强与接口桥接
fixtures/            开发检查脚本与 JS 测试
docs/                架构、验证、兼容性与审计
DEVELOPMENT_PLAN.md   原始分阶段开发方案
```

桌面包独立于根 Cargo workspace，使用自己的 manifest 和 Cargo.lock。
