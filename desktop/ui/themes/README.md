# Codex++ 主题素材与许可

桌面 0.5.0 收录当前 GitHub 主题市场全部 39 款和 Codex++ Windows 内置主题，共 40 款转换主题；加上本工具四套配色，共 44 款本地主题。

来源：[市场索引](https://github.com/BigPizzaV3/CodexPlusPlus-Themes/blob/main/index.json)、[Codex++ 内置素材](https://github.com/BigPizzaV3/CodexPlusPlus/tree/main/assets/inject/upstream/dream-skin)。作者、许可、来源和摘要见 [sources.json](sources.json)，提交快照见 [snapshot.json](../../../assets/themes/snapshot.json)。

原配置、图片及许可在仓库 assets/themes；每个主题的 LICENSE.md 副本和缩略图随管理前端分发。MIT、CC BY 4.0 等素材保留原许可、作者、来源及转换说明。缩略图由原图缩小生成。Windows 内置主题缺少 colors，转换配置明确采用上游默认颜色，原配置另外保留。

转换仅保留颜色及图片，不包含原 CSS、脚本、布局、品牌文案或推广链接。第三方素材许可不构成本项目其他代码的许可。

社区主题需主动加载清单并确认安装，不预打包社区素材；上游许可与 manifest 保存于本地独立主题文件。许可标签不代表工具确认了授权，使用时应核对原作者说明。

手动导入支持 schemaVersion 1 的 theme.json 及 PNG/JPEG/WebP；社区 ZIP 安装只读取校验通过的配置及图片，不执行包内代码。详见[适配分析](../../../docs/codex-theme-analysis.md)。
