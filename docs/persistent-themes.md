# 0.5.3 主题保持与自动恢复

应用主题时保存完整配色、壁纸、背景清晰度及恢复版本至应用配置目录 `active-theme.json`。同一程序以 `--theme-keeper` 模式启动独立隐藏进程，每三秒检查本机 Harness 页面，仅在样式缺失或版本不符时应用已保存主题。关闭管理窗口隐藏到托盘；退出管理工具保留主题及守护，不结束 Harness。守护不运行回收站操作，不修改 Harness 安装包、原生主题偏好或会话数据。

Harness 必须开启配置中的本机调试端口。断线时等待；重新连接时只接受唯一的 `dsh-app://app/` 页面，多个候选时不会自动选择。完整退出并重启 Harness 后页面 ID 可变化，守护会重新发现唯一页面。恢复会有数秒延迟。未开启调试端口的普通启动不能自动恢复。

“恢复 Harness 默认”先停止持久恢复，再清除页面样式。若 Harness 离线，自动恢复仍会停止，当前页面清理会报告连接错误。文件锁防止重复守护，也将应用、停止与自动恢复串行化。电脑重启、用户注销或手动结束守护后，需打开工具一次重新启动守护；本版不设置开机自启。程序文件更新前，建议先恢复默认以停止守护。
