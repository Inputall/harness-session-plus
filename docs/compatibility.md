诊断只依据明确 URL 选择页面，不以 Chrome 版本作为兼容性硬门槛。匹配 URL 不能证明安装包或后端身份。CDP WebSocket 仅接受配置端口的 127.0.0.1 /devtools/page/ 地址，拒绝代理、重定向、远端、凭据及 query。暂不支持 localhost、IPv6、远程 CDP 和其他页面 URL，以避免扩大范围。

公开源码、标题、DOM 行序号、端口、PID 或临时 target ID 均不能成为持久实例身份。证据不完整时不读取或关联旧回收站，也不执行数据操作。
