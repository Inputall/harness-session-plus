# 安全备份与迁移（0.9.0 开发版）

## 范围

入口：设置 → 安全备份与迁移。不需要 Harness 连接即可创建、预览或恢复工具备份。

默认包含 `settings.json`、`imported-themes.json`、`community-themes.json`、`community-themes/` 中的主题包、保存的皮肤副本 `saved-appearance.json` 和 `session-checkpoints.json`。检查点可能含工作区路径及会话摘录，不导出 Harness 会话数据库。启用中的皮肤会转换为该副本，不导出可自动执行的启用标志。主题的配色、壁纸及作者许可信息保留；只接受已有主题校验器支持的数据，不执行主题脚本或 CSS。

默认清除目标页面 ID 与本机可执行文件路径；勾选“保留本机连接路径”可保留原连接配置，但恢复时始终清除临时页面 ID。未保存设置时使用程序默认值。

可选包含本工具 `recycle.sqlite3`，包括会话标题、工作区、profile、会话 ID 和操作日志。使用 SQLite 在线备份读取一致快照，包含已提交 WAL，忙时最长等待约 30 秒。该数据库只记录本工具操作，不包含 Harness 消息正文、附件或项目文件。记录沿用原 profile，不能跨实例映射，也不能独立恢复 Harness 会话本体。

不导出凭据、原始日志、能力报告、关注清单、通知、后台任务或锁文件。ZIP 未加密，回收站记录与主题元数据仍可能含个人信息，请按需勾选并妥善保管。

## 创建与校验

创建后在工具数据目录 `backups/` 保存 ZIP 与旁路 `.sha256` 文件，可通过“打开备份目录”查看。ZIP 内的 `manifest.json` 记录格式版本、工具版本、创建时间、文件大小和每个文件 SHA256。

只接受当前相同版本的备份，最多 208 个 ZIP 条目，压缩文件不超过 64 MiB、解压累计不超过 192 MiB。拒绝非白名单路径、符号链接、重复文件、清单不一致、错误摘要、无效设置和不兼容数据库结构。SHA256 用于检查完整性；攻击者可以重写清单，因此摘要不等于数字签名或可信来源证明。

## 恢复流程

1. 选择 ZIP，点击“校验并预览”。查看新增、覆盖的文件以及回收站记录范围。
2. 卸载页面增强，点击“恢复 Harness 默认”停止主题守护。勾选覆盖确认，再点击“安排下次启动恢复”并确认。
3. 完全退出托盘中的管理工具，再打开与备份版本一致的工具版本。无需退出 Harness；恢复过程不调用 Harness 接口。
4. 下次启动先锁定工具数据目录、等待主题守护退出，再校验待恢复文件、创建 `before-restore-*.zip` 安全副本和独立回滚副本。数据库替换前检查点清空旧 WAL。
5. 写入恢复日志后逐文件替换。失败或启动时发现未完成日志，会恢复原文件并移除此次新增文件。回滚失败则停止启动，保留日志与副本，防止半恢复数据继续运行。
6. 完成后核对连接路径与端口。皮肤中心出现“备份恢复的皮肤”，手动选择后应用；自动回收站增强偏好关闭，需要重新主动安装增强。

预览清单没有列出的工具文件保留，唯一额外变更是关闭自动回收站增强偏好。备份不执行删除会话、恢复会话或清空操作。恢复管理记录并不代表这些会话在 Harness 中仍存在，应在原 profile 中重新核对。

安排后可点击“取消待恢复任务”，取消不修改当前配置。备份、源 ZIP、安全副本和回滚文件不会自动清理，也不会自动上传。

## 排查

- 显示已有管理实例：先从托盘退出旧版，再启动新版。旧版本不识别实例锁，升级前同样必须退出。
- 显示主题守护正在退出：等数秒后重试，或先取消恢复、恢复默认皮肤后再安排。
- 显示版本不兼容或完整性失败：当前配置不会被覆盖，重新选择同版本生成的完整 ZIP。
- 恢复失败且回滚未完成：保留整个工具数据目录、`restore-journal.json` 和 `restore-rollback/`，不要手动删除 SQLite WAL/SHM。修复权限或文件占用后再启动，程序会再次尝试回滚。
- 恢复成功后回收站为空：检查是否回到了原 Harness profile；备份不进行身份映射。

## 脱敏诊断

“导出脱敏诊断”创建固定字段 JSON 及 SHA256 文件，仅含工具版本、系统平台、时间、配置/数据库/主题文件存在状态、待恢复状态和后台任务登记状态。没有网络请求，不含正文、标题、路径、profile、令牌、配置具体值或原始错误日志。不代表 Harness 当前实际连接状态，连接问题仍需使用“检查连接”。

## 验证边界

自动测试使用临时目录和合成会话记录，覆盖在线 WAL 快照、原 profile 保留、无记录备份保留现有数据库、数据库替换、恢复中断回滚、回滚失败保留日志、损坏 ZIP 不改当前配置、非法路径/摘要/版本拒绝、数据库触发器拒绝及恢复皮肤不自动启用。前端模拟测试覆盖确认门槛、文件变更使预览失效、大小限制和错误展示。

尚未使用真实用户配置进行恢复，也未执行任何真实永久删除。自动测试不替代 Windows 桌面上的完整交互及断电恢复验收。
