# 皮肤中心验证（桌面 0.5.0）

## 实现范围

通过本机 CDP 向已识别 Harness 页面加入单个自有 style，覆盖实际安装包的 `--dsw-*` 主题变量。提供四套配色、40 款 Codex++ 转换主题、社区按需安装及手动导入。预览不加载远程内容，社区仅在用户主动操作时联网；不接受任意 CSS，不调用原生插件注册接口，不改原生外观偏好。卸载只移除本工具的 style。

这是页面级配色及壁纸覆盖，不是第三方插件安装器，也不是完整组件主题包。刷新或重启后需重新应用；代码语法、语义状态、部分原生窗口及硬编码颜色可能保留原色。

# 0.5.1 背景清晰度调整

新增 0–100% 的背景清晰度滑块，默认 70%。点击“应用到 Harness”后，通过降低面板、侧栏和背景层的遮挡显示壁纸；菜单、输入框、文字配色保持不变。纯配色主题不受影响。

真实 Harness 验证了 0%、70%、100% 三档：白色侧栏底色的 alpha 分别为 0.950、0.460、0.250，菜单和输入框仍为原主题底色。验证结束后恢复测试前的皮肤覆盖。记录：`target/wallpaper-clarity-live.json`。前端测试覆盖滑块数值传递，注入测试覆盖范围校验、遮挡变化及恢复。
